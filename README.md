# Automatic Attendance System Using Embedded System

## Overview
This project uses an ESP32 and MFRC522 RFID reader to automate attendance recording.

## Features
- RFID card registration
- Student identification
- Attendance tracking
- Serial monitor output

## Hardware Used
- ESP32
- MFRC522 RFID Module
- MIFARE RFID Cards/Tags
- RFID Cards
- Jumper Wires
- Breadboard 

## Files

### ESP32_Attendance_System.ino
Main attendance system code.

### RFID_Card_Configuration.ino
Used to write student information to RFID cards.

### Google_Sheets_Integration.gs
Google Apps Script used to receive attendance data and update the spreadsheet.

### Circuit_Diagram.png
Hardware wiring diagram of the project.
