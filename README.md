# Automatic Attendance System Using Embedded System

## Overview
This project uses an ESP32 and MFRC522 RFID reader to automate attendance recording.

## Features
- RFID card registration
- Student identification
- Attendance tracking
- Serial monitor output

## Hardware Used
- ESP32
- MFRC522 RFID Module
- RFID Cards
- Jumper Wires

## Files

### RFID_Card_Configuration.ino
Used to write student/card holder names to RFID cards and verify stored data.
